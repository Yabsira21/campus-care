CampusCare

CampusCare is a student clinic appointment booking app built with React and Vite.

Features
Browse available doctors
Filter doctors by department
View doctor profiles
Choose available appointment slots
Submit a validated booking form
View appointment confirmation

Tech Stack
React

Getting Started
1. Clone the repository
git clone <your-repository-url>
cd CampusCare
2. Install dependencies
npm install
3. Start the development server
npm run dev
